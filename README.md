# 光 / 互动解压页面

> 在线预览：[https://lieyangx.github.io/relax-light/](https://lieyangx.github.io/relax-light/)

一个无依赖的单文件互动页面。光点沿斜线持续向左上方飞行，点击、长按或按住空格会触发加速、音爆与短句；迎面光环、星图收集和可选节奏模式组成一套轻量玩法。

## 玩法

- **首次进入**：会自动打开玩法说明；点击左下角「玩法」按钮可以随时重新查看。
- **脉冲与过载**：点击左键 / 右键触发脉冲；长按进入持续过载，速度持续爬升，并不断生成音爆环；光标周围会显示蓄力进度。
- **完美释放**：前方会周期性出现迎面光环。长按蓄力，在光环与光点重合、蓄力环提示 `RELEASE` 时松开，触发 `PERFECT` 大音爆。
- **共鸣等级**：连续 `PERFECT` 或踩中节奏会提升共鸣，最高 `×5`；等级越高，完美音爆环越多，短句越亮。
- **星尘与星座**：点击、长按和完美释放都会积累星尘。每 5 点星尘点亮一颗星，30 点完成一个星座。前三个星座依次解锁冷白、极光紫、深空金以及对应短句组，之后继续累计星座次数。
- **节奏模式**：左下角 `RHYTHM` 按钮或 `R` 键开启。场景会按固定拍点脉冲；点击踩拍积累共鸣，松手踩拍释放额外光波。
- **配色**：首次解锁后左下角出现色点；点击色点或按 `C` 切换已解锁配色。默认仍是深空青蓝。
- **音乐**：背景音乐会循环播放，首次点击或关闭玩法说明后开始，左下角「音乐」按钮可以开关。
- **存档**：星尘、星座进度、已解锁配色、节奏模式、音乐开关和教程状态保存在浏览器 `localStorage` 中。清除该站点的本地数据即可重置进度。

## 操作

- 左键 / 右键任意位置：脉冲、蓄力、完美释放。
- 空格键：单击或按住空格，效果与鼠标一致。
- 移动端：轻触脉冲，长按蓄力；长按不会选中页面内容。
- `R`：切换节奏模式。
- `C`：切换已解锁配色。
- 左下角「音乐」：开启或关闭背景音乐。
- 无操作：页面会自动出现音爆环，并偶尔进行一次缓加速。

## 本地预览

直接双击 `index.html` 即可。也可以启动一个静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 发布

页面没有构建步骤，`index.html` 就是最终产物。仓库已经使用 GitHub Pages 的 `main / (root)` 方式发布，推送后等待 1–2 分钟即可更新：

```bash
git push
```

当前线上地址：

```text
https://lieyangx.github.io/relax-light/
```

如果重新配置 Pages，在仓库 **Settings → Pages** 中选择：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/ (root)`
