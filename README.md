# 光 / 互动解压页面

> 在线预览：[https://lieyangx.github.io/relax-light/](https://lieyangx.github.io/relax-light/)

一个无依赖的单文件互动页面。光点沿斜线持续向左上方飞行，点击、长按或按住空格会触发加速、音爆与短句；每一轮从零开始，点亮 3 个星座后进入带随机励志短句的结算场景。

## 玩法

- **单轮挑战**：每次进入都会从零开始；本轮目标是点亮 **3 个星座**。完成第三个星座后进入结算场景。
- **首次进入**：会自动打开玩法说明；点击左下角「玩法」按钮可以随时重新查看。
- **脉冲与过载**：点击左键 / 右键触发脉冲；长按进入持续过载，速度持续爬升，并不断生成音爆环；光标周围会显示蓄力进度。
- **完美释放**：前方会周期性出现迎面光环。长按蓄力，在光环与光点重合、蓄力环提示「松开」时松手，触发「完美」大音爆。
- **共鸣等级**：连续完美或踩中节奏会提升共鸣，最高 `×5`；等级越高，完美音爆环越多，短句越亮。
- **星尘与星座**：点击、长按和完美释放都会积累星尘。每 5 点星尘点亮一颗星，30 点完成一个星座。前三个星座依次解锁冷白、极光紫、深空金和对应短句组；完成第三个星座即通关。
- **节奏模式**：左下角「节奏」按钮或 `R` 键开启。它是独立的 **75 拍/分** 节拍挑战，节拍以画面脉冲为准，不跟随背景音乐：踩拍按下 +1 共鸣 / +1 星尘，踩拍松开 +2 星尘并放出光波，每 8 次踩拍额外 +4 星尘；开启后光环会与拍点对齐，方便把完美和踩拍叠加。不开启也能正常收集。
- **配色**：首次解锁后左下角出现色点；点击色点或按 `C` 键切换已解锁配色。每轮默认深空青蓝。
- **音乐**：背景音乐会循环播放，首次点击或关闭玩法说明后开始，左下角「音乐」按钮可以开关。
- **单轮数据**：星尘、星座、配色、节奏和踩拍次数每轮重置。浏览器只记住「玩法说明已读」和「音乐开关」两个界面偏好。
- **结算场景**：完成第三个星座后，会随机显示一句励志短句，并在三种结算色调中随机出现一种；结算会统计用时、星尘、完美次数、最高共鸣和踩拍次数。可以点击「继续游玩」关闭结算并保留当前星图，进入自由游玩；也可以点击「再次出发」重新开始。

### 数值速查

- 点击 / 轻触 / 空格：**+2 星尘**。
- 长按：每 **0.7 秒 +1**。
- 完美：**+6 + 命中后的共鸣等级**；首次为 +7，最高 `×5` 时为 +11。
- 节奏踩拍：按下 **+1**，松开 **+2**；每 8 次踩拍额外 **+4** 星尘。
- 1 颗星 = **5 星尘**；1 个星座 = **30 星尘**。
- 当前进度 = 总星尘除以 30 的余数；亮星数 = 当前进度除以 5 向下取整；完成星座数 = 总星尘除以 30 向下取整。
- 第 6 颗星随满 30 的完成动画点亮；右上角「星尘」显示当前星座进度。
- 右上角「本轮目标」达到 **3 / 3 星座** 即进入结算。

## 操作

- 左键 / 右键任意位置：脉冲、蓄力、完美释放。
- 空格键：单击或按住空格，效果与鼠标一致。
- 移动端：轻触脉冲，长按蓄力；长按不会选中页面内容。
- `R` 键：切换节奏模式。
- `C` 键：切换已解锁配色。
- 左下角「音乐」：开启或关闭背景音乐。
- 无操作：页面会自动出现音爆环，并偶尔进行一次缓加速。

## 本地预览

直接双击 `index.html` 即可。也可以启动一个静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 发布

页面没有构建步骤，`index.html` 就是最终产物。仓库已经使用 GitHub Pages 的 `main / (root)` 方式发布，推送后等待 1–2 分钟即可更新：

```bash
git push
```

当前线上地址：

```text
https://lieyangx.github.io/relax-light/
```

如果重新配置 Pages，在仓库 **Settings → Pages** 中选择：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/ (root)`
